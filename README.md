## Qualia App
Run the application to fuse the AMNE compiler with the tensor reduction:

```bash
python qualia_app.py "אמת והשגה מופשטת" --context שכל אור מציאות
```

Optional: provide a 5D tensor as JSON (nested lists):

```bash
python qualia_app.py "אמת והשגה מופשטת" --context שכל אור מציאות --tensor-json tensor.json
```
